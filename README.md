SEL-310 Web Engineering - Lab 1: HTML Fundamentals
Objective:
This assignment focuses on practicing HTML structure, semantic elements, and attributes without using CSS or JavaScript. The goal is to create well-structured web pages, display data in tables, and add basic interactivity using only HTML.
Tasks
Task 1: Table-Based Web Layout
Created a web page layout using <table> including:
Header
Navigation sidebar
Main content area
Footer
Used <thead>, <tbody>, and <tfoot> appropriately.
Applied rowspan and colspan for complex layout sections.
Included:
<figure> with <figcaption> for an image
<details> and <summary> for collapsible information
Task 2: Periodic Table (Without CSS)
Designed a Periodic Table using only <table> elements.
Used the bgcolor attribute for coloring different element groups.
Represented:
Atomic numbers using <sup>
Atomic mass using <sub>
Task 3: Resume Page (Using Semantic HTML)
Created a resume/profile page using semantic HTML tags:
<header> for name and designation
<nav> for quick links (Education, Skills, Contact, etc.)
<section> for education and experience

<article> for project or achievement descriptions

<footer> for contact information
